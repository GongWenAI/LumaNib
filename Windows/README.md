# LumaNib for Windows

Native C# / WPF app targeting Windows 10 1809+ and Windows 11 on x64.

- [Build and test](../docs/BUILDING.md)
- [English user guide](USER_GUIDE_EN.md)
- [中文使用说明](USER_GUIDE.md)

Source is in `src/`, portable logic tests in `tests/`. Cross-builds and logic tests
have passed on macOS. Native Windows UI, startup and recording behavior still
need device testing; compiling is not proof of Windows operation.
