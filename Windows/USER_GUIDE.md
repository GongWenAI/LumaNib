## 运行

完整解压后双击 LumaNib.exe。请保留同目录内的所有文件，不要只复制 exe，也不要在压缩包里直接运行。

目标：Windows 10 1809 或以上、Windows 11，64 位 Intel / AMD 电脑。程序自带 .NET 运行库，无需另装 .NET；普通用户权限运行，默认不添加开机启动，可在“通用”页主动开启。当前下载包未做商业代码签名。

此版本已交叉构建并通过 79 项逻辑检查，但尚未在 Windows 实机上验证操作、显示效果或 OBS 录制，Win11 未实机测试。

## 默认快捷键

- Ctrl + Alt + R：开关鼠标圆环。
- Ctrl + Alt + D：进入或退出画笔。
- Ctrl + Alt + Z：撤销上一笔。
- Ctrl + Alt + X：清空笔迹。
- Esc：退出画笔、取消快捷键录入。

在“全局快捷键”页点击输入框，直接按组合键，再点击“应用快捷键”。至少包含 Ctrl、Alt 或 Win；Esc 和 F12 保留。

## 画笔与圆环

左右半环分别选色，按下对应鼠标键时发光。进入画笔后圆环暂时隐藏，左键拖动画线，Esc 退出。退出后笔迹保留，同时允许正常点击下面的软件。

可选择按一下切换绘制，或按住快捷键绘制；也可开启自动淡出。关闭设置窗口后，程序留在系统托盘。双击托盘图标打开设置，右键菜单可退出程序。

## 首次测试

1. 两侧设置不同颜色，分别点击、长按左右键，观察发光。
2. 在浏览器或记事本中按 Ctrl + Alt + D 画线，Esc 退出，确认可以点击下面的内容。
3. 测试撤销、清空、自动淡出、按住绘制和自定义快捷键。
4. 退出并重开程序，确认设置保留。
5. OBS 选择整个显示器采集，先录一小段并播放检查。窗口采集和游戏采集可能遗漏效果。
6. 基本操作正常后，再测试 1–2 小时录制；有多屏时补测跨屏和不同缩放比例。

普通桌面和无边框窗口是主要场景；独占全屏、管理员程序或安全桌面可能限制覆盖与输入监听。

## 自检与反馈

先从托盘退出 LumaNib，再双击 Run-SelfTest.cmd。自检生成圆环与笔迹 PNG，并记录显示器信息，保存在：
%LOCALAPPDATA%\LumaNib\SelfTest\时间\

自检不模拟鼠标，也不证明快捷键、OBS 或长时间运行已经通过。
错误记录：%LOCALAPPDATA%\LumaNib\last-error.txt
设置文件：%LOCALAPPDATA%\LumaNib\settings.json

反馈入口：https://github.com/GongWenAI/LumaNib/issues
请说明系统版本、缩放比例、复现步骤；不要提供密码或含私人内容的录屏。

程序本身不录屏、不主动联网，不保存键盘内容或笔迹。点击项目地址会在默认浏览器中打开 GitHub。

## 登录后自动启动（1.59）

在“通用”页打开“登录后自动启动”，默认关闭。开启后只影响当前用户，登录时在菜单栏或托盘运行，不弹出设置窗口；关闭开关会移除登录启动项。

Mac 使用系统登录项，若显示等待允许，请通过页面按钮前往系统设置。建议应用放在“应用程序”中；外置磁盘需在登录时已连接并可访问。Windows 使用当前用户的启动项；移动完整程序文件夹或升级到新路径后，点击“更新自启路径”。若 Windows 在启动应用或任务管理器中禁用了此项，需要在那里重新允许。

Mac 已实际检查开启与关闭登记；没有进行注销或重启测试。Windows 的注册表操作与登录启动仍待实机验证。
